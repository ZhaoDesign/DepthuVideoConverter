Contour Control Tool Queue

Free public queue for MP4 / MOV depth conversion. Submit a GitHub issue with one small attachment or a public HTTPS video URL, then wait for the Actions job to finish.

Issue block

Keep this block in the issue body. Change only the values you need.

```queue
source=attachment
model=Small (fastest, ~99 MB)
resolution=Original
invert=false
smoothing=60
preserve_audio=true
```

How it works

  1. Open the issue template.
  2. Attach one small MP4 or MOV, or paste a public HTTPS video URL.
  3. GitHub Actions processes tasks one at a time and uploads the result as a 7-day artifact.
